# Модуль університетських опитувань — демонстрація

[Відкрити сайт](https://shproty-lab.github.io/survey-builder-demo/) · [Каталог історій](https://shproty-lab.github.io/survey-builder-demo/історії/)

Окремий публічний репозиторій для демонстрації замовнику: головна сторінка, каталог та 31 користувацька історія. Матеріали описують запланований продукт.

**Дата оновлення:** 2026-10-12. HTML отримано з коміту `7b11f86695db31c6e1b1294b5a2b732bd5689882`, гілка `docs/survey-builder-html` репозиторію `shproty-lab/documentation`. Структура відносних посилань і байти всіх 33 HTML збережені. [Контрольні суми](контрольні-суми.sha256).

## Публікація та оновлення

GitHub Pages публікує корінь гілки `main`; `.nojekyll` залишає HTML без обробки Jekyll. Для оновлення потрібно скопіювати актуальний `index.html` та каталог `історії/` з джерела, оновити контрольні суми й відправити коміт у `main`. Pages опублікує його автоматично.

Для локального перегляду відкрийте `index.html` у браузері разом із папкою `історії/`.
