# Модуль університетських опитувань — демонстрація

[Відкрити сайт](https://shproty-lab.github.io/survey-builder-demo/) · [Каталог історій](https://shproty-lab.github.io/survey-builder-demo/історії/)

Публічна HTML-копія для демонстрації замовнику: головна сторінка, каталог та користувацькі історії. Матеріали описують запланований продукт.

## Джерело копії

HTML надходить з репозиторію `shproty-lab/documentation`. Поточні гілка, коміт і кількість сторінок записуються автоматично у [джерело-копії.json](джерело-копії.json). Байти HTML і структура відносних посилань збережені; [контрольні суми](контрольні-суми.sha256) оновлюються разом із копією.

## Автоматичне оновлення

1. Змінити `index.html` або сторінки `історії/` у папці `документація/проєкт/конструктор-форм/демонстрація/` основного репозиторію.
2. Відправити коміт у `docs/survey-builder-html` або `main`. Поки презентація не перенесена в `main`, використовувати `docs/survey-builder-html`.
3. Workflow «Синхронізація демонстрації опитувань» перевірить HTML і відправить копію в `main` цього репозиторію. GitHub Pages автоматично оновить сайт.

Повторний ручний push у цей репозиторій не потрібен. Якщо синхронізація не завершилася, її журнал доступний у Actions основного репозиторію. Для ручного повтору там можна запустити `sync-survey-demo.yml` з потрібної гілки.

GitHub Pages публікує корінь `main`; `.nojekyll` залишає HTML без обробки Jekyll. Для локального перегляду відкрийте `index.html` разом із папкою `історії/`.
